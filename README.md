# EDGE90

Aplicación web de análisis probabilístico de fútbol.

- Datos reales históricos y fixtures públicos: Football-Data.co.uk.
- Modelo Poisson con fuerza ataque/defensa local-visitante, ponderación por recencia y shrinkage.
- Probabilidad 1X2, Over 1.5, Over 2.5, BTTS y doble oportunidad.
- Cuota justa del modelo.
- Referencia de mercado y edge solo cuando la fuente pública incluye cuotas.
- Backtest cronológico con Brier Score y Log Loss.
- Simulador Monte Carlo para gestión de bankroll.

No presenta apuestas como seguras ni garantiza beneficios. Si faltan datos, no inventa recomendaciones.
